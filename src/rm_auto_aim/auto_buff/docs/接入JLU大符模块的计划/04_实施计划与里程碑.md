# 实施计划与里程碑

## M0: auto_buff 包化与依赖收敛（0.5-1 周）

任务：
1. `auto_buff` 切换到 `package.xml + CMakeLists.txt`。
2. 删除 xmake 入口与 `iceoryx_deps` 规则依赖。
3. 形成依赖清单：可移植、可替换、可删除。

验收：
- `auto_buff` 成为标准 ROS2 包结构。
- 形成缺失依赖报告并可指导下一阶段改造。

## M1: robot_description 内聚（1-2 周）

任务：
1. 盘点并替换散落几何逻辑。
2. 新增法向/facing API。
3. 调试链路统一调用 `robot_description`。

验收：
- 几何计算路径唯一化。
- 现有装甲板回归通过。

## M2: 双模式升级（1 周）

任务：
1. 增加 `YAW_PLANE/FULL_SE3`。
2. 实现按 `robot_id/type` 自动选择模式。
3. 配置开关与降级策略。

验收：
- 默认配置行为与当前一致。
- 指定 mock 目标可启用 FULL_SE3 并输出稳定。

## M3: auto_buff Tracker ROS2 化（1-2 周）

任务：
1. 重写 tracker 侧监听器到 ROS2 topic/subscription。
2. TF 查询替换为 `tf2_ros`。
3. tracker 输入输出消息完成 `rm_interfaces` 对齐。

验收：
- tracker 在 ROS2 下稳定运行。
- 不依赖 `iceoryx` 运行时。

## M4: auto_buff 适配器接入（1 周）

任务：
1. 新增 `BuffTargetAdapter`。
2. 映射为 `TrackedRobot` 并接入 `GimbalPipelineNode` 合并缓存。
3. `SetMode` 与 target 白名单联动。

验收：
- 大符/小符模式下可稳定选中 buff 目标并驱动控制输出。
- 普通自瞄模式不受影响。

## M5: buff 专用选板与开火建议（2 周）

任务：
1. 增加 buff 选板策略。
2. 增加 buff 开火建议策略。
3. 调参、压测、可视化。

验收：
- 实车/离线回放命中率指标达标。
- 与旧链路无互相污染。
