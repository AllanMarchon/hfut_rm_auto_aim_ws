## Phase 1：主链路兜底（IPPE PnP + 单帧 yaw BA）

### 1.1 目标

在现有同步链路基础上，实现单帧 yaw 优化的完整闭环：

1. IPPE PnP 给出 `tvec` / `rvec` / `yaw_raw`
2. 单帧 yaw BA：固定 `tvec`、固定 `pitch=±15°`、固定 `roll=0°`，只优化 `yaw`
3. BA 失败自动回退 PnP 结果
4. 对每个检测输出扩展后的 `PoseEstimate`

### 1.5 `SingleYawRefiner` 实现逻辑

```cpp
// src/core/single_yaw_refiner.cpp

PoseEstimate SingleYawRefiner::refine(
    const PoseEstimate& pnp_result,
    const std::array<cv::Point2f, 4>& image_points,
    const std::array<cv::Point3f, 4>& object_points,
    const cv::Mat& K,
    const cv::Mat& D)
{
  PoseEstimate result = pnp_result;

  // Step 1: 确定 pitch 和 roll
  double pitch = pnp_result.pitch;
  double roll  = pnp_result.roll;
  if (std::isnan(pitch) || std::abs(pitch) < 1e-4) {
    pitch = config_.pitch_deg_default * M_PI / 180.0;
  }
  if (std::isnan(roll) || std::abs(roll) < 1e-4) {
    roll = config_.roll_deg_default * M_PI / 180.0;
  }

  // Step 2: 从 PnP rvec 提取 yaw 初值
  double yaw_init = pnp_result.yaw;

  // Step 3: 一维优化 yaw
  double yaw_opt = yaw_init;
  bool ok = optimizeYaw(yaw_opt, pnp_result.t, pitch, roll,
                        image_points, object_points, K, D);

  // Step 4: 有效性检查
  if (!ok || std::isnan(yaw_opt) || !std::isfinite(yaw_opt)) {
    result.mode = EstimateMode::PNP_VALID;
    result.quality_score = 0.5;
    result.reproj_error_refined = result.reproj_error_raw;
    return result;
  }

  // Step 5: 检查优化后 yaw 与初值差距是否过大
  double delta_yaw = std::abs(angleWrap(yaw_opt - yaw_init));
  if (delta_yaw > gate_.max_yaw_delta_deg * M_PI / 180.0) {
    result.mode = EstimateMode::PNP_VALID;
    result.quality_score = 0.5;
    result.reproj_error_refined = result.reproj_error_raw;
    return result;
  }

  // Step 6: 质量门控
  double refined_error = computeReprojError(yaw_opt, pnp_result.t, pitch, roll,
                                             image_points, object_points, K, D);
  if (gate_.require_finite && (!std::isfinite(refined_error))) {
    result.mode = EstimateMode::PNP_VALID;
    result.quality_score = 0.5;
    result.reproj_error_refined = result.reproj_error_raw;
    return result;
  }
  if (refined_error > gate_.max_reproj_error) {
    result.mode = EstimateMode::PNP_VALID;
    result.quality_score = std::max(0.0, 1.0 - refined_error / gate_.max_reproj_error);
    result.reproj_error_refined = result.reproj_error_raw;
    return result;
  }

  // Step 7: 成功 — 更新结果
  result.yaw = yaw_opt;
  result.R = yawPitchRollToRvec(yaw_opt, pitch, roll);
  result.mode = EstimateMode::SINGLE_BA_VALID;
  result.reproj_error_refined = refined_error;
  result.quality_score = std::max(0.0, 1.0 - refined_error / gate_.max_reproj_error);
  return result;
}
```

### 1.6 `optimizeYaw` 高斯-牛顿实现

```cpp
bool SingleYawRefiner::optimizeYaw(
    double& yaw, const cv::Vec3d& tvec,
    double pitch, double roll,
    const std::array<cv::Point2f, 4>& image_points,
    const std::array<cv::Point3f, 4>& object_points,
    const cv::Mat& K, const cv::Mat& D)
{
  double fx = K.at<double>(0, 0);
  double fy = K.at<double>(1, 1);
  double cx = K.at<double>(0, 2);
  double cy = K.at<double>(1, 2);

  for (int iter = 0; iter < config_.max_iterations; ++iter) {
    double J_sum = 0.0;
    double b_sum = 0.0;
    double cost = 0.0;

    // 构造当前 yaw 对应的旋转矩阵
    cv::Mat R_world_cam = yawPitchRollToMatrix(yaw, pitch, roll);
    cv::Vec3d t(tvec);

    for (int i = 0; i < 4; ++i) {
      cv::Vec3d P_obj(object_points[i].x, object_points[i].y, object_points[i].z);
      cv::Vec3d P_cam = R_world_cam * P_obj + t;

      if (P_cam[2] <= 1e-6) {
        return false;  // 点投影到相机后方
      }

      double inv_z = 1.0 / P_cam[2];
      double u_proj = fx * P_cam[0] * inv_z + cx;
      double v_proj = fy * P_cam[1] * inv_z + cy;

      double du = image_points[i].x - u_proj;
      double dv = image_points[i].y - v_proj;

      double r2 = du * du + dv * dv;

      // Huber loss weight
      double rho = 1.0;
      if (r2 > config_.huber_delta * config_.huber_delta) {
        rho = config_.huber_delta / std::sqrt(r2);
      }

      // 重投影对 yaw 的解析导数
      // P_cam 对 yaw 的导数：dP/dyaw = dR/dyaw * P_obj
      // 其中 dR/dyaw = R_yaw * skew([0,0,1]) * R_pitch_roll
      double dPx_dyaw = -P_cam[1];
      double dPy_dyaw =  P_cam[0];
      double dPz_dyaw = 0.0;

      double du_dyaw = fx * inv_z * (dPx_dyaw - P_cam[0] * inv_z * dPz_dyaw);
      double dv_dyaw = fy * inv_z * (dPy_dyaw - P_cam[1] * inv_z * dPz_dyaw);

      double J_i = du * du_dyaw + dv * dv_dyaw;
      double b_i = du * du_dyaw + dv * dv_dyaw;  // 实际应分离 J 和残差

      // 正确的高斯-牛顿：J^T W J Δx = J^T W r
      J_sum += rho * (du_dyaw * du_dyaw + dv_dyaw * dv_dyaw);
      b_sum += rho * (du_dyaw * du + dv_dyaw * dv);
      cost += rho * r2;
    }

    if (std::abs(J_sum) < 1e-10) {
      return true;  // 已收敛
    }

    double delta = b_sum / J_sum;

    // 线搜索：步长衰减
    double alpha = 1.0;
    for (int ls = 0; ls < 10; ++ls) {
      double yaw_try = yaw - alpha * delta;
      double cost_try = computeReprojError(yaw_try, tvec, pitch, roll,
                                            image_points, object_points, K, D);
      if (cost_try < cost) {
        yaw = yaw_try;
        break;
      }
      alpha *= 0.5;
    }

    if (std::abs(delta) < 1e-6) {
      return true;  // 收敛
    }
  }

  return true;
}
```

### 1.7 `ArmorPoseEstimatorAdapter::estimate()` 修改

修改 `src/core/armor_pose_estimator_adapter.cpp` 中 `estimate()` 方法：

```cpp
PoseEstimate ArmorPoseEstimatorAdapter::estimate(
    const ArmorDetection& detection,
    const cv::Mat& K, const cv::Mat& D)
{
  // === 现有 PnP 逻辑不变 ===
  PoseEstimate result;
  // ... solvePnP IPPE/Iterative ...
  // 填充 result.t / result.R / result.yaw / result.pitch / result.roll
  // result.reproj_error_raw = ...
  // result.valid = true/false
  // result.mode = result.valid ? PNP_VALID : LOST

  if (!result.valid) {
    return result;
  }

  // === 新增：单帧 yaw BA ===
  if (config_.refiner.mode != "none" && refiner_ != nullptr) {
    auto refined = refiner_->refine(
        result,
        {detection.keypoints[0], detection.keypoints[1],
         detection.keypoints[2], detection.keypoints[3]},
        getObjectPoints(detection.publish_type),
        K, D);

    if (refined.valid && refined.mode == EstimateMode::SINGLE_BA_VALID) {
      return refined;
    }
    // else: fall through, 返回 PnP 结果
  }

  result.mode = EstimateMode::PNP_VALID;
  result.quality_score = 0.5;
  return result;
}
```

### 2.5 `associate()` 实现逻辑

```cpp
std::vector<TrackedDetection> InternalIoUTrackerStrategy::associate(
    const std::vector<ArmorDetection>& detections,
    const rclcpp::Time& stamp)
{
  int N_tracks = tracks_.size();
  int N_dets   = detections.size();

  std::vector<TrackedDetection> results;
  results.reserve(N_dets);

  // 初始化结果：全部标记为未匹配
  for (const auto& det : detections) {
    TrackedDetection td;
    td.det = det;
    td.track_id = -1;
    td.matched = false;
    results.push_back(td);
  }

  if (N_tracks == 0 || N_dets == 0) {
    // 无历史轨迹：全部创建新 track
    for (auto& td : results) {
      int new_id = next_id_++;
      td.track_id = new_id;
      td.matched = true;
      TrackState ts;
      ts.id = new_id;
      ts.predicted_bbox = td.det.bbox;
      ts.center = cv::Point2f(td.det.bbox.x + td.det.bbox.width * 0.5f,
                              td.det.bbox.y + td.det.bbox.height * 0.5f);
      ts.age = 0;
      ts.hits = 1;
      ts.missed = 0;
      ts.last_stamp = stamp;
      ts.publish_type = td.det.publish_type;
      ts.publish_number = td.det.publish_number;
      ts.confirmed = (ts.hits >= config_.min_hits);
      tracks_.push_back(ts);
    }
    return results;
  }

  // 构建代价矩阵：max(N_tracks, N_dets) × max(N_tracks, N_dets)
  int dim = std::max(N_tracks, N_dets);
  cv::Mat cost = cv::Mat(dim, dim, CV_64F, cv::Scalar(1e6)); // 默认极高代价

  for (int i = 0; i < N_tracks; ++i) {
    for (int j = 0; j < N_dets; ++j) {
      double iou = computeIoU(tracks_[i].predicted_bbox, detections[j].bbox);

      // 门控：IoU 过低或中心距过大 → 匹配作废
      double center_dist = cv::norm(tracks_[i].center -
          cv::Point2f(detections[j].bbox.x + detections[j].bbox.width * 0.5f,
                      detections[j].bbox.y + detections[j].bbox.height * 0.5f));

      if (iou >= config_.iou_threshold &&
          center_dist <= config_.max_center_dist_px) {
        cost.at<double>(i, j) = 1.0 - iou;  // 代价 = 1 - IoU
      }
    }
  }

  // 匈牙利匹配
  auto matches = hungarianMatch(cost);

  // 处理匹配结果
  std::vector<bool> det_matched(N_dets, false);
  std::vector<bool> track_matched(N_tracks, false);

  for (const auto& m : matches) {
    int ti = m.x;  // track index
    int di = m.y;  // detection index
    if (ti >= N_tracks || di >= N_dets) continue;

    double iou = computeIoU(tracks_[ti].predicted_bbox, detections[di].bbox);
    double center_dist = cv::norm(tracks_[ti].center -
        cv::Point2f(detections[di].bbox.x + detections[di].bbox.width * 0.5f,
                    detections[di].bbox.y + detections[di].bbox.height * 0.5f));

    if (iou >= config_.iou_threshold &&
        center_dist <= config_.max_center_dist_px) {
      // 有效匹配
      results[di].track_id = tracks_[ti].id;
      results[di].matched = true;
      results[di].det.track_id = tracks_[ti].id;
      results[di].det.track_age = tracks_[ti].age;
      results[di].det.track_hits = tracks_[ti].hits;

      // 更新 track 状态
      tracks_[ti].predicted_bbox = detections[di].bbox;
      tracks_[ti].center = cv::Point2f(
          detections[di].bbox.x + detections[di].bbox.width * 0.5f,
          detections[di].bbox.y + detections[di].bbox.height * 0.5f);
      tracks_[ti].age++;
      tracks_[ti].hits++;
      tracks_[ti].missed = 0;
      tracks_[ti].last_stamp = stamp;
      tracks_[ti].confirmed = (tracks_[ti].hits >= config_.min_hits);

      det_matched[di] = true;
      track_matched[ti] = true;
    }
  }

  // 未匹配的 detection → 创建新 track
  for (int di = 0; di < N_dets; ++di) {
    if (!det_matched[di]) {
      int new_id = next_id_++;
      results[di].track_id = new_id;
      results[di].matched = true;
      results[di].det.track_id = new_id;

      TrackState ts;
      ts.id = new_id;
      ts.predicted_bbox = detections[di].bbox;
      ts.center = cv::Point2f(
          detections[di].bbox.x + detections[di].bbox.width * 0.5f,
          detections[di].bbox.y + detections[di].bbox.height * 0.5f);
      ts.age = 0;
      ts.hits = 1;
      ts.missed = 0;
      ts.last_stamp = stamp;
      ts.publish_type = detections[di].publish_type;
      ts.publish_number = detections[di].publish_number;
      ts.confirmed = false;
      tracks_.push_back(ts);
    }
  }

  // 未匹配的 track → missed++
  for (int ti = 0; ti < N_tracks; ++ti) {
    if (!track_matched[ti]) {
      tracks_[ti].missed++;
      tracks_[ti].hits = 0;  // 重置连续命中
    }
  }

  // 删除过期 track
  tracks_.erase(
    std::remove_if(tracks_.begin(), tracks_.end(),
      [this](const TrackState& t) {
        return t.missed > config_.max_missed;
      }),
    tracks_.end()
  );

  return results;
}
```

### 2.6 匈牙利匹配实现

`InternalIoUTrackerStrategy` 必须使用确定性的最优分配算法（Hungarian 或 LAPJV），不依赖 OpenCV 内置 API。

实现要求：

1. 代价矩阵维度为 `max(N_tracks, N_dets)` 的方阵，未门控候选填充大代价。
2. 仅接受通过 IoU 与中心距门控的匹配对。
3. 若仅有贪心实现，可作为临时调试开关，不得作为默认实现。

### 3.5 `RoiPcaCornerRefiner` 实现

#### 3.5.1 主流程

```cpp
RefineResult RoiPcaCornerRefiner::refine(
    const cv::Mat& frame,
    const ArmorDetection& detection)
{
  auto t_start = std::chrono::steady_clock::now();
  RefineResult result;
  result.refined_keypoints = detection.keypoints;  // 默认保留原始

  // Step 1: 从 4 个角点推断左右灯条 ROI
  auto [left_roi, right_roi] = extractLightBarROIs(detection.keypoints);

  // Step 2: 门控 — ROI 尺寸检查
  if (left_roi.area() < min_roi_area_ ||
      right_roi.area() < min_roi_area_) {
    result.ok = false;
    result.reason = RefineFailReason::ROI_TOO_SMALL;
    return result;
  }
  if (left_roi.area() > max_roi_area_ ||
      right_roi.area() > max_roi_area_) {
    result.ok = false;
    result.reason = RefineFailReason::ROI_TOO_LARGE;
    return result;
  }

  // Step 3: 超时检查
  if (elapsedMs(t_start) > config_.time_budget_ms) {
    result.ok = false;
    result.reason = RefineFailReason::TIMEOUT;
    return result;
  }

  // Step 4: PCA 灯条端点精修
  auto left_endpoints  = refineLightBar(frame, left_roi, detection.color);
  auto right_endpoints = refineLightBar(frame, right_roi, detection.color);

  if (!left_endpoints.ok || !right_endpoints.ok) {
    result.ok = false;
    result.reason = left_endpoints.ok ? right_endpoints.reason
                                      : left_endpoints.reason;
    return result;
  }

  // Step 5: 组装 4 个精修角点
  // 约定顺序：左上、右上、右下、左下
  std::array<cv::Point2f, 4> refined = {
    left_endpoints.top,     // 左上
    right_endpoints.top,    // 右上
    right_endpoints.bottom, // 右下
    left_endpoints.bottom   // 左下
  };

  // Step 6: 几何检查
  if (!validateGeometry(refined)) {
    result.ok = false;
    result.reason = RefineFailReason::GEOMETRY_INVALID;
    return result;
  }

  // Step 7: 成功
  result.ok = true;
  result.refined_keypoints = refined;
  result.refine_quality = computeQuality(refined, detection.keypoints);
  result.elapsed_ms = elapsedMs(t_start);
  result.reason = RefineFailReason::NONE;
  return result;
}
```

#### 3.5.2 左右灯条 ROI 提取

```cpp
std::pair<cv::Rect2f, cv::Rect2f> RoiPcaCornerRefiner::extractLightBarROIs(
    const std::array<cv::Point2f, 4>& corners)
{
  // corners 顺序：左上[0] 右上[1] 右下[2] 左下[3]

  // 左灯条 ROI：由 corners[0], corners[3] 确定
  cv::Point2f left_center = (corners[0] + corners[3]) * 0.5f;
  float left_half_h = cv::norm(corners[0] - corners[3]) * 0.5f * config_.roi_expand_ratio;
  float left_half_w = left_half_h * 0.4f;  // 灯条宽度约为高度的 0.4 倍

  cv::Rect2f left_roi(
    left_center.x - left_half_w,
    left_center.y - left_half_h,
    left_half_w * 2.0f,
    left_half_h * 2.0f
  );

  // 右灯条 ROI：由 corners[1], corners[2] 确定
  cv::Point2f right_center = (corners[1] + corners[2]) * 0.5f;
  float right_half_h = cv::norm(corners[1] - corners[2]) * 0.5f * config_.roi_expand_ratio;
  float right_half_w = right_half_h * 0.4f;

  cv::Rect2f right_roi(
    right_center.x - right_half_w,
    right_center.y - right_half_h,
    right_half_w * 2.0f,
    right_half_h * 2.0f
  );

  // 裁剪到图像边界
  left_roi &= cv::Rect2f(0, 0, frame_cols_, frame_rows_);
  right_roi &= cv::Rect2f(0, 0, frame_cols_, frame_rows_);

  return {left_roi, right_roi};
}
```

#### 3.5.3 PCA 灯条端点精修

```cpp
struct LightBarEndpoints {
  bool ok{false};
  cv::Point2f top;
  cv::Point2f bottom;
  RefineFailReason reason{RefineFailReason::NONE};
};

LightBarEndpoints RoiPcaCornerRefiner::refineLightBar(
    const cv::Mat& frame,
    const cv::Rect2f& roi,
    const fyt::EnemyColor color)
{
  LightBarEndpoints result;

  // Step 1: 提取 ROI 图像
  cv::Rect roi_int(
    static_cast<int>(roi.x), static_cast<int>(roi.y),
    static_cast<int>(roi.width), static_cast<int>(roi.height)
  );
  roi_int &= cv::Rect(0, 0, frame.cols, frame.rows);
  if (roi_int.width < 3 || roi_int.height < 3) {
    result.reason = RefineFailReason::ROI_TOO_SMALL;
    return result;
  }

  cv::Mat roi_img = frame(roi_int);

  // Step 2: 颜色通道增强
  cv::Mat gray;
  if (color == fyt::EnemyColor::RED) {
    // 红色灯条：用红色通道减去蓝色通道
    cv::Mat channels[3];
    cv::split(roi_img, channels);
    gray = channels[2] - channels[0];  // R - B
  } else {
    // 蓝色灯条：用蓝色通道减去红色通道
    cv::Mat channels[3];
    cv::split(roi_img, channels);
    gray = channels[0] - channels[2];  // B - R
  }

  // Step 3: 二值化（OTSU）
  cv::Mat binary;
  cv::threshold(gray, binary, 0, 255, cv::THRESH_BINARY | cv::THRESH_OTSU);

  // Step 4: 提取亮区点集
  std::vector<cv::Point2f> bright_points;
  cv::findNonZero(binary, bright_points);
  // 转换到 ROI 内的局部坐标
  for (auto& p : bright_points) {
    p.x += roi.x;
    p.y += roi.y;
  }

  if (bright_points.size() < static_cast<size_t>(config_.min_bright_points)) {
    result.reason = RefineFailReason::TOO_FEW_BRIGHT_POINTS;
    return result;
  }

  // Step 5: PCA
  cv::Mat data(bright_points.size(), 2, CV_32F);
  for (size_t i = 0; i < bright_points.size(); ++i) {
    data.at<float>(i, 0) = bright_points[i].x;
    data.at<float>(i, 1) = bright_points[i].y;
  }

  cv::PCA pca(data, cv::Mat(), cv::PCA::DATA_AS_ROW);

  // 特征值比例检查
  float lambda1 = pca.eigenvalues.at<float>(0);
  float lambda2 = pca.eigenvalues.at<float>(1);
  if (lambda2 / (lambda1 + lambda2) < 1.0 - config_.pca_stability_threshold) {
    result.reason = RefineFailReason::PCA_UNSTABLE;
    return result;
  }

  // Step 6: 沿主方向搜索端点
  cv::Point2f mean(pca.mean.at<float>(0), pca.mean.at<float>(1));
  cv::Point2f dir(pca.eigenvectors.at<float>(0, 0),
                  pca.eigenvectors.at<float>(0, 1));

  // 将亮区点沿主方向投影
  float min_proj = std::numeric_limits<float>::max();
  float max_proj = std::numeric_limits<float>::lowest();
  for (const auto& p : bright_points) {
    float proj = (p.x - mean.x) * dir.x + (p.y - mean.y) * dir.y;
    min_proj = std::min(min_proj, proj);
    max_proj = std::max(max_proj, proj);
  }

  float extend = (max_proj - min_proj) * 0.1f;  // 外扩 10%

  // Step 7: 在极值点附近搜索明暗交界
  cv::Point2f top_pt = mean + (min_proj - extend) * dir;
  cv::Point2f bottom_pt = mean + (max_proj + extend) * dir;

  // 沿主方向在极值点附近搜索最大梯度位置
  // 在 mean ± λ·dir 方向上采样灰度值，找到梯度最大的点
  auto searchEdge = [&](cv::Point2f start, cv::Point2f direction,
                         int search_range, int search_steps) -> cv::Point2f {
    cv::Point2f best_pt = start;
    float max_grad = 0.0f;

    for (int s = -search_steps; s <= search_steps; ++s) {
      cv::Point2f pt = start + (search_range * s / search_steps) * direction;

      // 边界检查
      if (pt.x < 0 || pt.x >= frame.cols - 1 ||
          pt.y < 0 || pt.y >= frame.rows - 1) continue;

      // 沿垂直于主方向的方向采样梯度
      cv::Point2f perp_dir(-direction.y, direction.x);
      float grad = 0.0f;
      for (int t = -2; t <= 2; ++t) {
        cv::Point2f sample_pt = pt + t * perp_dir;
        if (sample_pt.x >= 1 && sample_pt.x < frame.cols - 1 &&
            sample_pt.y >= 1 && sample_pt.y < frame.rows - 1) {
          float dx = frame.at<uchar>(
              static_cast<int>(sample_pt.y),
              static_cast<int>(sample_pt.x + 1)) -
              frame.at<uchar>(
              static_cast<int>(sample_pt.y),
              static_cast<int>(sample_pt.x - 1));
          grad += std::abs(dx);
        }
      }
      if (grad > max_grad) {
        max_grad = grad;
        best_pt = pt;
      }
    }
    return best_pt;
  };

  // 沿主方向搜索端点（灰度梯度最大处）
  int search_range = static_cast<int>((max_proj - min_proj) * 0.2f);
  result.top = searchEdge(top_pt, dir, search_range, 10);
  result.bottom = searchEdge(bottom_pt, -dir, search_range, 10);

  result.ok = true;
  return result;
}
```

#### 3.5.4 几何验证

```cpp
bool RoiPcaCornerRefiner::validateGeometry(
    const std::array<cv::Point2f, 4>& corners)
{
  // 检查面积（需为正，且不能太小/太大）
  double area = cv::contourArea(
    std::vector<cv::Point2f>(corners.begin(), corners.end())
  );
  if (area < min_area_ || area > max_area_) {
    return false;
  }

  // 检查凸性
  std::vector<cv::Point2f> pts(corners.begin(), corners.end());
  if (!cv::isContourConvex(pts)) {
    return false;
  }

  // 检查长宽比
  float width_top    = cv::norm(corners[0] - corners[1]);
  float width_bottom = cv::norm(corners[3] - corners[2]);
  float height_left  = cv::norm(corners[0] - corners[3]);
  float height_right = cv::norm(corners[1] - corners[2]);

  float avg_width  = (width_top + width_bottom) * 0.5f;
  float avg_height = (height_left + height_right) * 0.5f;

  float aspect_ratio = avg_width / std::max(1.0f, avg_height);
  if (aspect_ratio < config_.min_aspect_ratio ||
      aspect_ratio > config_.max_aspect_ratio) {
    return false;
  }

  return true;
}
```

### 4.4 滑窗 BA 求解器设计

滑窗内每帧有 4 个变量 `[tx, ty, tz, yaw]`，固定 `pitch=±15°`、`roll=0°`。

总目标函数：

```
E = E_reproj + λ_p E_prior + λ_m E_motion
```

其中：
- **E_reproj**：所有帧所有角点的重投影误差（Huber loss）。
- **E_prior**：每帧对 PnP 结果的弱先验约束，防止深度漂移。
- **E_motion**：相邻帧间 `[tx,ty,tz,yaw]` 的平滑约束。

#### 重投影误差解析导数

对于帧 k 的角点 i（i = 0,1,2,3）：

```
P_cam = R(yaw_k) · R_pitch · P_obj_i + t_k
u_proj = project(P_cam, K)

残差 r_i = u_meas_i - u_proj
```

雅可比 J（2×4）：

- **对 t_k**：
  - `du/dtx = fx / z`, `du/dty = 0`, `du/dtz = -fx·x / z²`
  - `dv/dtx = 0`, `dv/dty = fy / z`, `dv/dtz = -fy·y / z²`

- **对 yaw_k**：
  - `dP_cam/dyaw = dR/dyaw · R_pitch · P_obj_i`
  - `dR/dyaw = skew([0,0,1]) · R(yaw) · R_pitch`
  - 即：`dP/dyaw = [-y, x, 0]^T`
  - `du/dyaw = fx · (dx/dyaw · z - x · dz/dyaw) / z²`
  - `dv/dyaw = fy · (dy/dyaw · z - y · dz/dyaw) / z²`

### 4.6 `solveSlidingWindow` 高斯-牛顿求解

```cpp
bool SlidingWindowRefiner::solveSlidingWindow(
    SlidingWindowState& window,
    const cv::Mat& K, const cv::Mat& D,
    Eigen::Vector3d& t_out, double& yaw_out, double& final_error)
{
  const size_t N = window.size();
  if (N < static_cast<size_t>(sw_config_.min_frames_)) {
    return false;
  }

  // 检查时间跨度
  if (window.timeSpanMs() > sw_config_.max_time_span_ms_) {
    // 窗口内帧时间跨度过大，可能混入错误观测
    return false;
  }

  double fx = K.at<double>(0, 0);
  double fy = K.at<double>(1, 1);
  double cx = K.at<double>(0, 2);
  double cy = K.at<double>(1, 2);

  // 初始状态：各帧 PnP 结果
  int state_dim = N * 4;  // [tx0,ty0,tz0,yaw0, tx1,ty1,tz1,yaw1, ...]
  Eigen::VectorXd x(state_dim);
  for (size_t k = 0; k < N; ++k) {
    x[4*k + 0] = window.frames()[k].t_init.x();
    x[4*k + 1] = window.frames()[k].t_init.y();
    x[4*k + 2] = window.frames()[k].t_init.z();
    x[4*k + 3] = window.frames()[k].yaw_init;
  }

  for (int iter = 0; iter < sw_config_.max_opt_iters_; ++iter) {
    // 构建 H 和 b
    Eigen::MatrixXd H = Eigen::MatrixXd::Zero(state_dim, state_dim);
    Eigen::VectorXd b = Eigen::VectorXd::Zero(state_dim);
    double total_cost = 0.0;

    // --- 1. 重投影误差边 ---
    for (size_t k = 0; k < N; ++k) {
      const auto& frame = window.frames()[k];

      double t[3] = {x[4*k+0], x[4*k+1], x[4*k+2]};
      double yaw = x[4*k+3];
      double pitch = frame.pitch;
      double roll  = frame.roll;

      // 构造 R(yaw) * R_pitch
      // R_yaw · R_pitch_roll
      double cy = std::cos(yaw), sy = std::sin(yaw);
      double cp = std::cos(pitch), sp = std::sin(pitch);
      double cr = std::cos(roll), sr = std::sin(roll);

      // R = R_yaw * R_pitch_roll
      // R_yaw = [[cy, -sy, 0], [sy, cy, 0], [0, 0, 1]]
      // R_pitch_roll = R_pitch * R_roll
      // 假定 R_pitch_roll 是 [[cp, 0, sp], [0, 1, 0], [-sp, 0, cp]] * R_roll
      // 简化：roll=0 时 R_pitch_roll = [[cp, 0, sp], [0, 1, 0], [-sp, 0, cp]]

      for (int i = 0; i < 4; ++i) {
        // 物体坐标
        Eigen::Vector3d P_obj(
          object_points_cache_[i].x,
          object_points_cache_[i].y,
          object_points_cache_[i].z
        );

        // R_pitch_roll * P_obj
        double X_r = cp * P_obj.x() + sp * P_obj.z();
        double Y_r = P_obj.y();
        double Z_r = -sp * P_obj.x() + cp * P_obj.z();

        // R_yaw * (R_pitch_roll * P_obj)
        double X_c = cy * X_r - sy * Y_r + t[0];
        double Y_c = sy * X_r + cy * Y_r + t[1];
        double Z_c = Z_r + t[2];

        if (Z_c <= 1e-6) {
          // 点投影到相机后方 — 惩罚
          H(4*k+2, 4*k+2) += 1000.0;  // 强推 z > 0
          b(4*k+2) += 1000.0 * 1.0;
          continue;
        }

        double inv_z = 1.0 / Z_c;

        double u_proj = fx * X_c * inv_z + cx;
        double v_proj = fy * Y_c * inv_z + cy;

        double du = frame.keypoints[i].x - u_proj;
        double dv = frame.keypoints[i].y - v_proj;

        // 角点置信度 → 权重
        double conf = std::clamp(frame.keypoint_conf[i], 0.1f, 1.0f);
        double sigma = sw_config_.sigma_kp_min_ + (1.0 - conf) * sw_config_.sigma_kp_scale_;
        double weight = 1.0 / (sigma * sigma);

        // Huber loss
        double r2 = du * du + dv * dv;
        double rho = 1.0;
        if (r2 > sw_config_.huber_delta_ * sw_config_.huber_delta_) {
          rho = sw_config_.huber_delta_ / std::sqrt(r2);
        }

        weight *= rho;
        total_cost += weight * r2;

        // 雅可比 JTJ 和 JTr（2 × 4 块）
        // du/dt:
        double J01 = fx * inv_z;           // du/dtx
        double J02 = 0.0;                  // du/dty
        double J03 = -fx * X_c * inv_z * inv_z;  // du/dtz

        // dv/dt:
        double J11 = 0.0;                  // dv/dtx
        double J12 = fy * inv_z;           // dv/dty
        double J13 = -fy * Y_c * inv_z * inv_z;  // dv/dtz

        // du/dyaw: dX_c/dyaw = -Y_c + t偏移, dY_c/dyaw = X_c - t偏移
        // 实际：d(R_yaw * [X_r, Y_r, Z_r])/dyaw = [-Y_c+t[1]-t[1], X_c-t[0]+t[0], 0]
        // 简化：d/dyaw = [-sy*X_r - cy*Y_r, cy*X_r - sy*Y_r, 0]
        //          = [-Y_c_local, X_c_local, 0]
        double X_c_local = cy * X_r - sy * Y_r;
        double Y_c_local = sy * X_r + cy * Y_r;

        double dX_dyaw = -Y_c_local;   // = -Y_c_local
        double dY_dyaw =  X_c_local;   // =  X_c_local
        double dZ_dyaw = 0.0;

        double J04 = fx * (dX_dyaw * Z_c - X_c * dZ_dyaw) * inv_z * inv_z;
        double J14 = fy * (dY_dyaw * Z_c - Y_c * dZ_dyaw) * inv_z * inv_z;

        // 填入 H 和 b（4×4 对角块 + 残差）
        int idx = 4 * k;

        // H += weight * J^T * J, b += weight * J^T * r
        auto addToH = [&](int r, int c, double v) {
          H(idx + r, idx + c) += weight * v;
        };

        addToH(0, 0, J01 * J01);
        addToH(0, 2, J01 * J03);
        addToH(0, 3, J01 * J04);
        addToH(2, 2, J03 * J03);
        addToH(2, 3, J03 * J04);
        addToH(3, 3, J04 * J04);

        addToH(1, 1, J12 * J12);
        addToH(1, 2, J12 * J13);
        addToH(1, 3, J12 * J14);
        addToH(2, 2, J12 * J13 + J03 * J03);  // 注意 J13 贡献到 tz 行
        // ... 完整填充（省略对称部分的冗余代码）

        b(idx + 0) += weight * J01 * du;
        b(idx + 1) += weight * J12 * dv;
        b(idx + 2) += weight * (J03 * du + J13 * dv);
        b(idx + 3) += weight * (J04 * du + J14 * dv);
      }
    }

    // --- 2. PnP 先验边 ---
    for (size_t k = 0; k < N; ++k) {
      const auto& frame = window.frames()[k];
      int idx = 4 * k;

      double wx = 1.0 / (sw_config_.sigma_prior_xy * sw_config_.sigma_prior_xy);
      double wy = 1.0 / (sw_config_.sigma_prior_xy * sw_config_.sigma_prior_xy);
      double wz = 1.0 / (sw_config_.sigma_prior_z * sw_config_.sigma_prior_z);
      double wyaw = 1.0 / (sw_config_.sigma_prior_yaw * sw_config_.sigma_prior_yaw);

      H(idx + 0, idx + 0) += wx;
      H(idx + 1, idx + 1) += wy;
      H(idx + 2, idx + 2) += wz;

      b(idx + 0) += wx * (frame.t_init.x() - x[idx + 0]);
      b(idx + 1) += wy * (frame.t_init.y() - x[idx + 1]);
      b(idx + 2) += wz * (frame.t_init.z() - x[idx + 2]);

      // yaw 先验（注意 wrap）
      double dyaw = angleWrap(x[idx + 3] - frame.yaw_init);
      H(idx + 3, idx + 3) += wyaw;
      b(idx + 3) += wyaw * (-dyaw);
    }

    // --- 3. 帧间平滑边 ---
    for (size_t k = 1; k < N; ++k) {
      int idx0 = 4 * (k - 1);
      int idx1 = 4 * k;

      double dt = (window.frames()[k].stamp - window.frames()[k-1].stamp).seconds();
      dt = std::max(dt, 0.001);  // 防止除零

      // 自适应平滑权重
      double ws_xy  = 1.0 / (sw_config_.sigma_smooth_xy * sw_config_.sigma_smooth_xy * dt);
      double ws_z   = 1.0 / (sw_config_.sigma_smooth_z * sw_config_.sigma_smooth_z * dt);
      double ws_yaw = 1.0 / (sw_config_.sigma_smooth_yaw * sw_config_.sigma_smooth_yaw * dt);

      // dx = x_k - x_{k-1}
      for (int d = 0; d < 3; ++d) {
        double w = (d == 2) ? ws_z : ws_xy;
        H(idx0 + d, idx0 + d) += w;
        H(idx0 + d, idx1 + d) -= w;
        H(idx1 + d, idx0 + d) -= w;
        H(idx1 + d, idx1 + d) += w;
        b(idx0 + d) += w * (x[idx1 + d] - x[idx0 + d]);
        b(idx1 + d) -= w * (x[idx1 + d] - x[idx0 + d]);
      }

      // yaw 平滑（处理 wrap）
      double dyaw = angleWrap(x[idx1 + 3] - x[idx0 + 3]);
      H(idx0 + 3, idx0 + 3) += ws_yaw;
      H(idx0 + 3, idx1 + 3) -= ws_yaw;
      H(idx1 + 3, idx0 + 3) -= ws_yaw;
      H(idx1 + 3, idx1 + 3) += ws_yaw;
      b(idx0 + 3) += ws_yaw * dyaw;
      b(idx1 + 3) -= ws_yaw * dyaw;
    }

    // --- 4. 求解 ---
    Eigen::VectorXd dx = H.ldlt().solve(b);

    // --- 5. 更新 ---
    for (size_t k = 0; k < N; ++k) {
      x[4*k + 0] += dx[4*k + 0];
      x[4*k + 1] += dx[4*k + 1];
      x[4*k + 2] += dx[4*k + 2];
      x[4*k + 3] += dx[4*k + 3];
      // yaw normalize（保持 [-π, π]）
      x[4*k + 3] = std::atan2(std::sin(x[4*k + 3]), std::cos(x[4*k + 3]));
    }

    // 收敛检查
    if (dx.norm() < 1e-6) break;
  }

  // 返回最新帧结果
  size_t last = N - 1;
  t_out = Eigen::Vector3d(x[4*last + 0], x[4*last + 1], x[4*last + 2]);
  yaw_out = x[4*last + 3];

  // 检查结果有效性
  if (!std::isfinite(t_out.norm()) || !std::isfinite(yaw_out)) {
    return false;
  }

  return true;
}
```

```cpp
// SORT 输出 → 回填 track_id（依据 bbox IoU 反查）
void MuitSortTrackerStrategy::backfillTrackIds(
    std::vector<TrackedDetection>& results,
    const std::vector<muit_obj_tracker::TrackResult>& sort_results,
    const std::vector<ArmorDetection>& original_dets)
{
  for (auto& td : results) {
    td.track_id = -1;
    td.matched = false;
  }

  std::vector<bool> det_used(original_dets.size(), false);

  for (const auto& sr : sort_results) {
    // 按 bbox IoU 反查当前帧检测
    double best_iou = 0.0;
    int best_idx = -1;

    cv::Rect sr_rect(sr.bbox_x, sr.bbox_y, sr.bbox_width, sr.bbox_height);

    for (size_t i = 0; i < original_dets.size(); ++i) {
      if (det_used[i]) continue;

      cv::Rect2f det_rect = original_dets[i].bbox;
      cv::Rect det_rect_int(
        static_cast<int>(det_rect.x), static_cast<int>(det_rect.y),
        static_cast<int>(det_rect.width), static_cast<int>(det_rect.height)
      );

      double iou = computeIoU(sr_rect, det_rect_int);
      if (iou > best_iou) {
        best_iou = iou;
        best_idx = static_cast<int>(i);
      }
    }

    if (best_idx >= 0 && best_iou > 0.1) {
      results[best_idx].track_id = sr.track_id;
      results[best_idx].matched = true;
      results[best_idx].det.track_id = sr.track_id;
      det_used[best_idx] = true;
    }
  }
}
```

### 6.4 `LatestTaskQueue` 实现

```cpp
template <typename T>
class LatestTaskQueue {
public:
  void push(const T& task) {
    std::lock_guard<std::mutex> lock(mutex_);
    latest_task_ = task;
    has_task_ = true;
    cv_.notify_one();
  }

  bool popLatest(T& task) {
    std::unique_lock<std::mutex> lock(mutex_);
    cv_.wait(lock, [this] { return has_task_ || stop_; });

    if (stop_ && !has_task_) return false;

    task = std::move(latest_task_);
    has_task_ = false;
    return true;
  }

  // 非阻塞尝试获取
  bool tryPopLatest(T& task) {
    std::lock_guard<std::mutex> lock(mutex_);
    if (!has_task_) return false;
    task = std::move(latest_task_);
    has_task_ = false;
    return true;
  }

  void stop() {
    std::lock_guard<std::mutex> lock(mutex_);
    stop_ = true;
    cv_.notify_all();
  }

private:
  std::mutex mutex_;
  std::condition_variable cv_;
  T latest_task_;
  bool has_task_{false};
  bool stop_{false};
};
```

```cpp
void EnhanceWorker::workerLoop() {
  while (running_) {
    EstimationTask task;
    if (!task_queue_.popLatest(task)) {
      continue;  // 已停止
    }

    auto t_start = std::chrono::steady_clock::now();
    EnhanceResult result;
    result.frame_id = task.frame_id;
    result.track_id = task.track_id;
    result.quality_ok = false;

    // Step 1: 角点精修
    RefineResult refined;
    if (corner_refiner_) {
      // 从 ROI 图像中提取检测信息
      ArmorDetection det;
      det.bbox = task.bbox;
      det.keypoints = task.raw_keypoints;
      det.keypoint_conf = task.keypoint_conf;
      det.publish_type = task.publish_type;
      det.publish_number = task.publish_number;

      refined = corner_refiner_->refine(task.image_roi, det);
    }

    const auto& corners = refined.ok
      ? refined.refined_keypoints
      : task.raw_keypoints;

    // Step 2: 滑窗 BA
    if (sliding_refiner_) {
      PoseEstimate refined_pose = sliding_refiner_->refine(
        task.raw_pose_candidate, corners,
        task.raw_pose_candidate.object_points,  // 需从任务中传入
        task.K, task.D);

      if (refined_pose.valid &&
          refined_pose.mode == EstimateMode::SW_BA_VALID) {
        result.estimate = refined_pose;
        result.quality_ok = true;
      }
    }

    result.elapsed_ms = elapsedMs(t_start);

    // Step 3: 发布结果
    result_queue_.push(result);
  }
}
```

### 6.7 一致性校验

```cpp
bool isResultConsistent(
    const EnhanceResult& result,
    uint64_t expected_frame_id,
    int expected_track_id,
    const rclcpp::Time& current_stamp,
    double max_age_ms)
{
  // frame_id 和 track_id 必须匹配
  if (result.frame_id != expected_frame_id) return false;
  if (result.track_id != expected_track_id) return false;

  // 结果不能太旧
  double age_ms = (current_stamp - result.estimate.stamp).seconds() * 1000.0;
  if (age_ms > max_age_ms) return false;

  return true;
}
```

### 状态机实现（贯穿所有 Phase）

```cpp
// 在 ArmorPoseEstimatorAdapter 或专门的 StateMachine 类中

EstimateMode current_mode_ = EstimateMode::LOST;
int bad_count_ = 0;
int good_count_ = 0;
static constexpr int kBadThreshold = 2;
static constexpr int kGoodThreshold = 3;

EstimateMode transition(const PoseEstimate& result) {
  switch (current_mode_) {
    case EstimateMode::LOST:
      if (result.valid && result.mode >= EstimateMode::PNP_VALID) {
        current_mode_ = EstimateMode::PNP_VALID;
        good_count_ = 1;
        bad_count_ = 0;
      }
      break;

    case EstimateMode::PNP_VALID:
      if (!result.valid) {
        bad_count_++;
        if (bad_count_ >= kBadThreshold) {
          current_mode_ = EstimateMode::LOST;
        }
      } else if (result.mode >= EstimateMode::SINGLE_BA_VALID) {
        good_count_++;
        bad_count_ = 0;
        if (good_count_ >= kGoodThreshold) {
          current_mode_ = EstimateMode::SINGLE_BA_VALID;
        }
      } else {
        bad_count_ = 0;
      }
      break;

    case EstimateMode::SINGLE_BA_VALID:
      if (!result.valid) {
        bad_count_++;
        if (bad_count_ >= kBadThreshold) {
          current_mode_ = EstimateMode::PNP_VALID;
        }
      } else if (result.mode == EstimateMode::SW_BA_VALID) {
        good_count_++;
        bad_count_ = 0;
        if (good_count_ >= kGoodThreshold) {
          current_mode_ = EstimateMode::SW_BA_VALID;
        }
      } else {
        good_count_ = 0;
      }
      break;

    case EstimateMode::SW_BA_VALID:
      if (!result.valid) {
        bad_count_++;
        if (bad_count_ >= kBadThreshold) {
          current_mode_ = EstimateMode::SINGLE_BA_VALID;
        }
      } else if (result.mode < EstimateMode::SW_BA_VALID) {
        bad_count_++;
        if (bad_count_ >= kBadThreshold) {
          current_mode_ = result.mode;
        }
      } else {
        bad_count_ = 0;
      }
      break;
  }

  return current_mode_;
}
```

## 15. 面向反向扩展的模块化拆分规范

本节定义“可从 `armor_detector_nn` 反向扩展到 `armor_detector`”的模块化边界。后续实现应尽量按本节拆分，避免算法逻辑绑定在某一 detector 内。

### 15.1 模块拆分总览

建议拆分为 6 个相对独立模块：

1. `pose_core`
- 职责：`PnP` 求解、`PoseEstimate` 标准化、基础质量门控。
- 输入：`object_points/image_points/K/D`。
- 输出：`PoseEstimate`。
- 禁止依赖：NN 专有结构、ROS 消息结构。

2. `pose_refiner`
- 职责：`IPoseRefiner` 抽象与实现（`SingleYawRefiner`、`SlidingWindowRefiner`）。
- 输入：`PoseEstimate + keypoints + camera model`。
- 输出：精化后的 `PoseEstimate`。
- 禁止依赖：具体 detector 的检测结果类型。

3. `track_core`
- 职责：多目标关联与轨迹管理（`ITrackerStrategy`、`internal_iou`、`muit_sort_adapter`）。
- 输入：统一观测结构 `TrackObservation`。
- 输出：`TrackAssignment`（含 `track_id`）。
- 禁止依赖：姿态估计内部实现。

4. `corner_refine_core`
- 职责：角点精修（`ICornerRefiner`、`RoiPcaCornerRefiner`）。
- 输入：`FrameView + OrderedKeypoints + ColorHint`。
- 输出：`RefineResult`。
- 禁止依赖：tracker 或 BA 实现细节。

5. `async_orchestrator`
- 职责：异步任务编排（`LatestTaskQueue`、worker、超时回退、结果合并）。
- 输入：轻量任务 DTO。
- 输出：增强结果或 fallback 触发。
- 禁止依赖：具体优化算法实现细节（通过接口注入）。

6. `adapter_layer`
- 职责：`armor_detector_nn` 与未来 `armor_detector` 的数据映射。
- 输入：各 detector 原生检测结构。
- 输出：统一 DTO（供 1~5 模块使用）。
- 说明：差异应被限制在该层，不向核心模块扩散。

### 15.2 公共 DTO（跨模块唯一数据契约）

以下结构建议定义在共享头文件（例如 `core/common_types.hpp`）：

1. `OrderedArmorObservation`
- `bbox`
- `std::array<cv::Point2f,4> keypoints_ordered`
- `float confidence`
- `std::string type_hint`（small/large）
- `std::string id_hint`（number 标签）
- `EnemyColor color_hint`
- `rclcpp::Time stamp`

2. `TrackObservation`
- `bbox`
- `center`
- `confidence`
- `type_hint`
- `id_hint`

3. `TrackAssignment`
- `track_id`
- `confirmed`
- `track_age`
- `consecutive_hits`
- `total_hits`

4. `PoseEstimate`
- 保持现有 `translation/rotation/rvec/tvec` 兼容
- `mode`
- `reproj_error_raw`
- `reproj_error_refined`
- `quality_score`
- `track_id`

5. `RefineResult`
- `ok`
- `refined_keypoints`
- `reason`
- `elapsed_ms`
- `refine_quality`

要求：以上 DTO 不得包含 detector 特有字段命名（如 `publish_type`）以外的硬编码语义，差异通过 adapter 转换。

### 15.3 目录建议（按模块落盘）

建议在 `armor_detector_nn/include/armor_detector_nn/core/` 与 `src/core/` 下形成镜像结构：

1. `pose_core/`
2. `pose_refine/`
3. `tracker/`
4. `corner_refine/`
5. `async/`
6. `adapters/`

其中：

1. `adapters/nn_adapter.*`：`ArmorDetection <-> OrderedArmorObservation`
2. 未来新增 `adapters/armor_adapter.*`：传统 detector 数据映射

### 15.4 依赖方向约束（必须遵守）

仅允许单向依赖：

`adapter_layer -> (track_core, corner_refine_core, pose_core, pose_refiner, async_orchestrator)`

并满足：

1. `pose_core` 不依赖 `track_core`。
2. `track_core` 不依赖 `pose_core`。
3. `corner_refine_core` 不依赖 `pose_refiner`。
4. `async_orchestrator` 仅依赖接口，不直接依赖具体实现类。

### 15.5 工厂与配置分层

1. 工厂分层
- `TrackerFactory`
- `CornerRefinerFactory`
- `PoseRefinerFactory`
- `OrchestratorFactory`

2. 配置分层
- `common`：跨 detector 通用参数（门控、阈值、窗口大小）
- `nn`：模型输出相关参数（keypoint remap、label map 语义）
- `armor`：传统视觉特有参数（阈值、形态学核等）

3. 配置原则
- 核心模块读取 `common`，adapter 层读取 detector 专属配置。

### 15.6 反向扩展实施步骤

为支持后续扩展到 `armor_detector`，按下列顺序执行：

1. 先将当前 `nn` 链路接入公共 DTO（通过 `nn_adapter`）。
2. 将 `PnP + single_yaw + sliding_window` 收敛到 `pose_core/pose_refine`。
3. 将 `internal_iou` 与 `muit_sort_adapter` 收敛到 `track_core`。
4. 将 `RoiPcaCornerRefiner` 收敛到 `corner_refine_core`。
5. 引入 `armor_adapter`，仅实现数据映射，不复制算法。
6. 在 `armor_detector` 侧复用工厂与核心模块，完成反向扩展。

### 15.7 验收标准（模块化维度）

1. 替换 detector 不改核心算法：`adapter` 之外文件改动不超过 10%。
2. 关闭任一增强模块不影响主链路可用性。
3. `nn` 与 `armor` 两条链路可共享同一套 `pose_refiner` 与 `track_core` 二进制。
4. 单元测试可在无 ROS 节点条件下覆盖 `pose_core/track_core/corner_refine_core`。
