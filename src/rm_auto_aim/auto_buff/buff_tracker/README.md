# buff_tracker（状态估计语义）

`buff_tracker` 在当前迁移方案中仅承担能量机关状态估计职责，不再承担：

- 云台控制
- 弹道解算
- 开火命令发布

目标输出语义为“目标状态”，由下游 `gimbal_pipeline` 统一完成选板、控制与开火决策。

## 保留模块

- 小符/大符状态估计核心
- 因子图与拟合相关模块（`factors`、`targets`、`buff_fitter`、`types`）
- 状态预测与时间一致性处理

## 迁移约束

- 与通信/硬件相关的旧 iceoryx 监听器、云台状态读取、AimCommand 发布逻辑将逐步移除。
- 统一改为 ROS2 话题输入输出。
- 包内节点最终语义收敛为“状态估计节点”。
