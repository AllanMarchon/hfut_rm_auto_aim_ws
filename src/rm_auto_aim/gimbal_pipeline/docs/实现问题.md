# 二、关键问题 & 优化（重点）

---

## ⚠️ 问题1：theta_center 设计有“逻辑抵消”

你现在：

```cpp
theta_hit   = yaw_k + omega_k * t_bullet;
theta_center = yaw_k + omega_k * weighting_delay_s_;
dtheta = theta_hit - theta_center;
```

展开：

```cpp
dtheta = omega_k * (t_bullet - delay)
```

👉 **yaw_k 被完全抵消了！**

---

## ❗ 这意味着什么？

你的 reward 实际只在做：

> “子弹时间 vs delay 是否匹配”

而**完全不关心当前指向是否对准装甲板中心**

---

## ✅ 正确做法（关键修改）

你需要引入一个“真正的目标角”：

```cpp
double theta_target = yaw_k;  // 或装甲板实际朝向
double theta_center = theta_target + omega_k * weighting_delay_s_;
double dtheta = angles::normalize_angle(theta_hit - theta_center);
```

👉 或更清晰：

```cpp
double dtheta = angles::normalize_angle(
    (yaw_k + omega_k * t_bullet)   // 子弹命中角
  - (theta_target + omega_k * delay) // 最优角
);
```

📌 本质：

> **比较“命中时角度”和“理想击打角”**

---

## ⚠️ 问题3：sigma 没有考虑角速度（你之前设计过）

你现在：

```cpp
sigma = clamp(sigma_eff, min, max);
```

👉 但你之前的思路是：

> ω ↑ → σ ↓

现在没体现！

---

## ✅ 推荐改法

```cpp
double sigma_dynamic = sigma_eff / (1.0 + beta * std::abs(omega_k));
sigma = std::clamp(sigma_dynamic, sigma_min, sigma_max);
```

👉 或：

```cpp
sigma = sigma_min + (sigma_eff - sigma_min) * exp(-beta * abs(omega_k));
```

📌 效果：

* 高速 → 更精准
* 低速 → 更稳定

---
