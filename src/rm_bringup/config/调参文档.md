# 调参文件说明

本文档说明当前 SP25 `aim_v2` 接入 HFUT ROS2 项目后，调参时真正需要看的文件。

目标链路：

```text
video/camera -> /image_raw
virtual_serial/real_serial -> /serial/receive
aim_v2_node -> /armor_solver/cmd_gimbal
rm_serial_driver -> 下位机
```

## 先看这几个

### 1. 启动总入口

文件：

```text
src/rm_bringup/config/launch_params_decoupled.yaml
```

用途：

- 选择离线还是实车。
- 选择视频源、相机源、虚拟串口或真实串口。
- 设置 `aim_v2` 的启动默认参数。

常调参数：

```yaml
robot: 'video_test'
image_source: 'video'
virtual_serial: true

aim_v2:
  enable_fire: false
  control_backend: 'aimer'
  detector_type: 'yolo'
  async_inference: false
```

建议：

- 离线第一次跑：`control_backend: 'aimer'`，`async_inference: false`。
- 跑通后再切：`control_backend: 'planner'`。
- 上车前和离线调试都保持：`enable_fire: false`。

### 2. 视频源参数

文件：

```text
src/rm_bringup/config/video_player_params.yaml
```

什么时候看：

```yaml
image_source: 'video'
```

常调参数：

```yaml
video_path: "decoded/output.mp4"
fps: 120.0
camera_info_url: "package://rm_bringup/config/camera_info.yaml"
```

说明：

- `video_path` 是最常改的。
- 相对路径按运行 `ros2 launch` 时的当前目录解析；不确定时写绝对路径。
- 如果 PnP 距离、角度明显不对，检查 `camera_info_url` 指向的内参。

### 3. 虚拟下位机参数

文件：

```text
src/rm_bringup/config/virtual_serial_params.yaml
```

什么时候看：

```yaml
virtual_serial: true
```

常调参数：

```yaml
roll: 0.0
pitch: 0.0
yaw: 180.0
vision_mode: 1
```

说明：

- `roll/pitch/yaw` 是模拟下位机反馈的云台姿态，单位为度。
- `vision_mode` 会写入 `/serial/receive.mode`。
- 当前 `aim_v2` 约定：`0` 推导敌方红色，`1` 推导敌方蓝色。

### 4. SP25 自瞄核心参数

文件：

```text
src/rm_auto_aim/aim_v2/config/aim_v2.yaml
```

什么时候看：

- 调 SP25 检测、跟踪、解算、Aimer、Planner/TinyMPC。
- 视频和虚拟串口链路已经跑通后，再重点看这个文件。

常调参数：

```yaml
enemy_color: "red"
yolo_name: yolov5
device: CPU
min_confidence: 0.8

yaw_offset: 0
pitch_offset: 1.5

min_detect_count: 5
max_temp_lost_count: 15

fire_thresh: 0.0035
max_yaw_acc: 50
max_pitch_acc: 100
```

说明：

- `launch_params_decoupled.yaml` 决定用 `yolo` 还是 `traditional`，这里决定 YOLO 模型和算法细节。
- `yaw_offset/pitch_offset` 必须等方向确认后再调。
- `camera_matrix/R_camera2gimbal/t_camera2gimbal` 是实车精度关键，离线跑通前不要乱改。

### 5. 视频内参

文件：

```text
src/rm_bringup/config/camera_info.yaml
```

什么时候看：

- 视频源 PnP、距离、角度明显不对。
- 换了视频来源或相机标定。

说明：

- 这是 `video_player_params.yaml` 中 `camera_info_url` 指向的文件。
- 如果只是测试节点能不能跑，不要优先改这里。

## 一般不用看的文件

### 旧神经网络检测器参数

文件：

```text
src/rm_bringup/config/video_test/armor_detector_nn.yaml
```

什么时候才看：

```yaml
detector_type: 'armor_detector_nn'
```

并且启动旧解耦链路，例如：

```text
bringup_decoupled.launch.py
bringup_pipeline.launch.py
```

说明：

- 这个不是 SP25 `aim_v2` 的 YOLO 参数。
- SP25 `aim_v2` 的参数在 `src/rm_auto_aim/aim_v2/config/aim_v2.yaml`。

### 旧 gimbal_pipeline 参数

文件：

```text
src/rm_bringup/config/<robot>/gimbal_pipeline.yaml
```

说明：

- 这是旧 `gimbal_pipeline` 链路的参数。
- 当前目标是跑 SP25 `aim_v2_node`，一般不要先调这里。

## 推荐调参流程

### 离线第一次跑

1. 改 `launch_params_decoupled.yaml`：

```yaml
robot: 'video_test'
image_source: 'video'
virtual_serial: true

aim_v2:
  enable_fire: false
  control_backend: 'aimer'
  detector_type: 'yolo'
  async_inference: false
```

2. 改 `video_player_params.yaml`：

```yaml
video_path: "你的测试视频路径"
fps: 30.0
```

3. 改 `virtual_serial_params.yaml`：

```yaml
yaw: 180.0
pitch: 0.0
vision_mode: 1
```

4. 启动：

```bash
ros2 launch rm_bringup bringup_v2.launch.py
```

5. 检查：

```bash
ros2 topic echo /serial/receive --once
ros2 topic hz /image_raw
ros2 topic echo /armor_solver/cmd_gimbal
```

### 跑通后再调

1. 调 `aim_v2.yaml` 的 `min_confidence`、`yaw_offset`、`pitch_offset`。
2. 切 `control_backend: 'planner'`。
3. 再调 Planner/TinyMPC 参数。
4. 最后再考虑 `async_inference: true`。

## 不要优先改的东西

- 不要一开始改真实串口协议。
- 不要一开始改 `gimbal_pipeline.yaml`。
- 不要一开始改相机外参，除非你明确知道当前标定不对。
- 不要打开 `enable_fire`，直到方向、串口协议、下位机解析全部确认。
