# 选板与开火策略扩展（buff 专用）

## 1. 为什么需要新策略

现有 `ArmorSelector` 与 `FireAdviceEngine` 多处基于装甲板 yaw 平面语义，不直接等价于风车叶片语义。

## 2. 策略分层

1. 目标选择层
- 保留现有装甲板策略。
- 新增 buff 策略：按 JLU 的叶片状态（激活/未激活、预测击打窗口）选择候选。

2. 开火建议层
- 保留现有装甲板开火判定。
- 新增 buff 判定：结合叶片法向、击打窗、飞行时间预测。

## 3. 与 robot_description 的关系

- 策略层不再自行推导几何。
- 统一调用 `robot_description` 内聚 API 获取：
  - 世界位置
  - 法向
  - facing 余弦
  - 预测时刻几何

## 4. 逐步演进

Phase A（先跑通）
- buff 仍走“单目标击打点”语义。
- 复用现有 ballistic + controller。

Phase B（增强）
- 选板改为多候选叶片策略。
- 开火建议引入 buff 专用概率模型。
