# 🧭 一、总体目标

你希望实现一个**模块化、可扩展的多目标跟踪系统框架**，该系统能够：

1. 维护一组动态的目标跟踪模型（`models`），支持目标的**加入、更新与退出**；
2. 支持不同的跟踪器设计（例如 SORT、DeepSORT、Composite、KalmanNetTracker 等）；
3. 允许在不破坏现有滤波器结构的情况下，构建“复合目标”跟踪（例如由四个角点子模型组成的组合体）；
4. 在匹配阶段支持多种策略（欧氏距离、IOU、IOU+距离混合等）；
5. 在未来可扩展至基于图像特征（ReID）或神经滤波器（KalmanNet）的版本；
6. 在 C++ 框架下实现（可集成到 ROS 或独立项目中）。

---

# 🧩 二、系统分层设计需求

## （1）底层：滤波模型层 `IModel`

系统中所有滤波器均基于抽象接口 `IModel`，提供通用的预测与更新方法。
你当前已有的滤波器都是对单点 `(x, y, z)` 状态进行跟踪的。

**需求：**

* 支持多种滤波模型：卡尔曼滤波、扩展卡尔曼滤波、KalmanNet、IMM 等；
* 接口统一，便于替换；
* 预测、更新和获取状态接口固定；
* 未来可在滤波层实现自学习或神经网络结构。

```cpp
class IModel {
public:
    virtual ~IModel() = default;
    virtual void predict() = 0;
    virtual void update(const Detection& det) = 0;
    virtual Eigen::VectorXd getState() const = 0;
};
```

---

## （2）中层：复合目标层 `CompositeModel`

你希望在不破坏单点滤波结构的前提下，实现复合对象跟踪。

**需求：**

* 由若干子 `IModel`（如四个角点滤波器）组成；
* 在接口上仍表现为 `IModel` 子类；
* 通过 `predict()` 和 `update()` 管理所有子模型；
* 提供高层几何信息（例如 ROI 边界框、中心点）；
* 允许上层以 IOU+距离等指标对目标进行匹配。

```cpp
class CompositeModel : public IModel {
private:
    std::vector<std::shared_ptr<IModel>> sub_models;
public:
    void predict() override;
    void update(const Detection& det) override;
    Eigen::VectorXd getState() const override; // 返回几何中心
    cv::Rect getPredictedROI() const;          // 提供2D框用于匹配
};
```

---

## （3）上层：跟踪器层 `ITracker`

不同的多目标跟踪算法（如 SORT、DeepSORT、ByteTrack、CompositeTracker）都要实现统一接口。

**需求：**

* 每个跟踪器内部维护一组 models；
* 支持生命周期管理（TTL）：

  * 匹配成功 → ttl 归零；
  * 未匹配 → ttl++；
  * ttl 超限 → 移除；
* 匹配阶段使用 KM（Hungarian）算法；
* 匹配策略可配置（IOU、距离、混合、置信度等）；
* 输出统一的跟踪结果结构体。

```cpp
class ITracker {
public:
    virtual ~ITracker() = default;
    virtual void predict() = 0;
    virtual void update(const std::vector<Detection>& detections) = 0;
    virtual std::vector<TrackResult> getTracks() const = 0;
    virtual void reset() = 0;
};
```

---

## （4）跟踪器实现层

你希望支持以下几类具体实现：

| 跟踪器类型              | 描述                 | 匹配方式         |
| ------------------ | ------------------ | ------------ |
| `SortTracker`      | 经典 SORT 算法，卡尔曼+IOU | IOU          |
| `DeepSortTracker`  | SORT + ReID 特征匹配   | IOU + 特征距离   |
| `CompositeTracker` | 由四点模型组成的组合体        | IOU + 几何中心距离 |
| `KalmanNetTracker` | 使用 KalmanNet 滤波器   | 距离或特征相似度     |

---

## （5）调度与策略管理层 `TrackerManager`

负责系统中不同类型跟踪器的统一管理和切换。

**需求：**

* 可以通过配置文件或运行时选择使用的跟踪器；
* 支持热切换；
* 提供统一的外部接口：

  * `predict()`
  * `update(detections)`
  * `getTracks()`

```cpp
enum class TrackerType { SORT, DEEPSORT, COMPOSITE, KALMANNET };

class TrackerManager {
private:
    std::unique_ptr<ITracker> tracker;
    TrackerType current_type;
public:
    TrackerManager(TrackerType t);
    void setTrackerType(TrackerType t);
    void predict();
    void update(const std::vector<Detection>& detections);
    std::vector<TrackResult> getTracks() const;
};
```

# ⚙️ 三、跟踪流程逻辑

系统的运行循环如下：

```cpp
while (true) {
    // 1️⃣ 接收检测结果
    std::vector<Detection> detections = detector.getDetections(frame);

    // 2️⃣ 状态预测
    trackerManager.predict();

    // 3️⃣ 数据关联 (KM / IOU / 距离)
    trackerManager.update(detections);

    // 4️⃣ 获取输出轨迹
    auto tracks = trackerManager.getTracks();

    // 5️⃣ 可视化或发布
    visualizer.drawTracks(frame, tracks);
}
```

# 🧮 四、匹配与生命周期管理细节

## 匹配逻辑

* 使用 Hungarian/Kuhn–Munkres 算法；
* 代价矩阵根据跟踪器类型不同：

  * SORT：IOU；
  * Composite：`cost = α * (1 - IOU) + (1 - α) * (distance / scale)`；
  * DeepSORT：`cost = β * (1 - cosine(feature)) + (1 - β) * (1 - IOU)`。

## 生命周期控制

* 每个 model 具有 `ttl`；
* 匹配成功 → `ttl = 0`；
* 未匹配 → `ttl++`；
* `ttl > max_ttl` → 从 `models` 中移除。

# 🧠 六、可扩展性要求

1. **可配置性：**

   * 使用 YAML/JSON 配置匹配阈值、权重、TTL 等参数；
   * 可在运行时动态加载。

2. **算法可插拔性：**

   * 新增一个 `Tracker` 子类即可接入；
   * 不影响现有模块；
   * 不修改接口层。

3. **视觉特征预留：**

   * 当前匹配只使用几何（IOU、距离）；
   * 但在 `Detection` 与 `IModel` 中预留 feature 接口；
   * 未来可直接扩展到 ReID 特征匹配。

4. **支持复合目标建模：**

   * 例如四点、六点、关键点组合；
   * `CompositeModel` 为统一抽象。

5. **兼容未来神经滤波器：**

   * 例如 KalmanNet；
   * 只需实现 `IModel` 接口即可接入。

| 匹配模块             | 数据关联（KM）  | 支持 IOU、距离、混合代价              |
| 生命周期             | 模型增删      | TTL 管理机制                    |
| 配置系统             | 运行时参数控制   | JSON / YAML                 |
