# 测试验收与回滚方案

## 1. 测试分层

1. 单元测试
- `TrackedRobotUsage` 双模式位置/法向/facing 计算。
- `auto_buff` 关键算法模块（fitter/trajectory/factors）回归。
- 边界：空 offset、非法 quaternion、single-armor 语义。

2. 集成测试
- `auto_buff` ROS2 节点单包构建与启动。
- `gimbal_pipeline` 在普通自瞄模式回归。
- `big_buff/small_buff` 模式目标选择与命令输出。

3. 回放与实机
- 离线包回放：稳定性与时延。
- 实机：丢包、切模式、超时恢复。

## 2. 验收指标

- 装甲板模式：行为与当前版本一致（误差阈值内）。
- buff 模式：目标稳定跟随，无异常抖动/跳变。
- 模式切换：100% 可恢复，无残留锁定状态。
- 依赖侧：不再依赖 `iceoryx_deps` 规则。

## 3. 回滚策略

1. 配置级回滚
- `external_targets.buff.enable=false`
- `robot_description.default_projection_mode=yaw_plane`

2. 代码级回滚
- adapter 单独编译开关。
- 新策略注册开关，可退回旧策略。
- auto_buff detector/tracker 可独立停用，不影响 armor 主链路。

3. 故障兜底
- FULL_SE3 数据异常自动降级 YAW_PLANE。
- buff 超时自动失效，不影响 armor 主链路。
