# 调参文件说明

本文档说明当前 v2 分支保留 SP `aim_v2` 后，调参时真正需要看的文件。

目标链路：

```text
video/camera -> /image_raw
virtual_serial/real_serial -> /serial/receive
aim_v2_node -> /armor_solver/cmd_gimbal
rm_serial_driver -> 下位机
```

## 先看这几个

### 1. 启动总入口

文件：

```text
src/rm_bringup/config/launch_params_decoupled.yaml
```

用途：

- 选择视频、MindVision 或 Hik 相机。
- 选择虚拟串口或真实串口。
- 设置 `aim_v2` 的启动默认参数。

离线视频调试常用配置：

```yaml
image_source: 'video'
virtual_serial: true

aim_v2:
  enable_fire: false
  control_backend: 'aimer'
  detector_type: 'yolo'
  async_inference: false
```

### 2. 视频源参数

文件：

```text
src/rm_bringup/config/video_player_params.yaml
```

常调参数：

```yaml
video_path: "你的测试视频路径"
fps: 30.0
camera_info_url: "package://rm_bringup/config/camera_info.yaml"
```

说明：

- `video_path` 是最常改的。
- 相对路径按运行 `ros2 launch` 时的当前目录解析；不确定时写绝对路径。
- 如果 PnP 距离、角度明显不对，检查 `camera_info_url` 指向的内参。

### 3. 虚拟下位机参数

文件：

```text
src/rm_bringup/config/virtual_serial_params.yaml
```

常调参数：

```yaml
roll: 0.0
pitch: 0.0
yaw: 180.0
vision_mode: 1
```

说明：

- `roll/pitch/yaw` 是模拟下位机反馈的云台姿态，单位为度。
- `vision_mode` 会写入 `/serial/receive.mode`。
- 当前 `aim_v2` 约定：`0` 推导敌方红色，`1` 推导敌方蓝色。

### 4. SP 自瞄核心参数

文件：

```text
src/rm_auto_aim/aim_v2/config/aim_v2.yaml
```

什么时候看：

- 调 SP 检测、跟踪、解算、Aimer、Planner/TinyMPC。
- 视频和虚拟串口链路已经跑通后，再重点看这个文件。

常调参数：

```yaml
enemy_color: "red"
yolo_name: yolov5
device: CPU
min_confidence: 0.8

yaw_offset: 0
pitch_offset: 1.5

min_detect_count: 5
max_temp_lost_count: 15

fire_thresh: 0.0035
max_yaw_acc: 50
max_pitch_acc: 100
```

### 5. 视频内参

文件：

```text
src/rm_bringup/config/camera_info.yaml
```

只在视频源 PnP、距离、角度明显不对，或换了视频来源/相机标定时修改。

## 推荐调参流程

1. 改 `launch_params_decoupled.yaml`，确认 `image_source: 'video'`、`virtual_serial: true`、`enable_fire: false`。
2. 改 `video_player_params.yaml`，填真实视频路径和帧率。
3. 改 `virtual_serial_params.yaml`，设置 `yaw/pitch/vision_mode`。
4. 第一次排查先启动传统检测器，并临时关闭串口模式限制：

```bash
ros2 launch rm_bringup bringup_v2.launch.py \
  image_source:=video \
  virtual_serial:=true \
  require_serial:=false \
  respect_mode:=false \
  enable_fire:=false \
  detector_type:=traditional \
  control_backend:=aimer \
  enemy_color:=red \
  derive_enemy_color_from_mode:=false
```

如果视频里是蓝色装甲板，把 `enemy_color:=red` 改成 `enemy_color:=blue`。

5. 检查：

```bash
ros2 topic echo /serial/receive --once
ros2 topic hz /image_raw
ros2 topic echo /armor_solver/cmd_gimbal
```

6. Foxglove 里先看 `/gimbal_pipeline/debug/image`。`D` 开头的是 detector 原始检测结果，`T` 开头的是 tracker/模型结果。只有 `D` 没有 `T` 时，优先检查敌方颜色、tracker 和内参；没有 `D` 时，优先调 `threshold`、`min_confidence`、视频曝光和视频路径。

## 仿真闭环验证流程

目标是让 Webots 仿真器从图像识别、云台跟随到 `fire_advice` 评分完整闭环。不要一开始就开火，按下面顺序排查。

Webots 相机内参、仿真外参、云台方向符号和仿真弹速的默认值集中在：

```text
src/rm_bringup/config/sim_params.yaml
```

长期参数优先改这个文件；临时排查可以继续在 `ros2 launch` 命令行里覆盖同名参数。

### 1. 先不开火，只看识别和指令

```bash
ros2 launch rm_bringup bringup_sim.launch.py \
  launch_webots:=true \
  detector_type:=traditional \
  control_backend:=aimer \
  enable_fire:=false
```

另开终端检查：

```bash
ros2 topic hz /image_raw
ros2 topic hz /serial/receive
ros2 topic echo /armor_solver/cmd_gimbal --once
```

Foxglove 先看 `/gimbal_pipeline/debug/image`：

- `D` 是 detector 原始检测结果。
- `T` 是 tracker/模型目标。
- 左上角第二行会显示当前 `target_id` 和 `distance`。
- 有 `D` 但没有 `T`，优先查敌方颜色、模式、内参和 tracker。
- 没有 `D`，优先查仿真画面、灯条阈值、`min_confidence` 和传统检测参数。

可直接导入仓库里的 Foxglove 布局：

```text
src/rm_bringup/foxglove/auto_aim_debug.layout.json
```

导入后默认会打开调试图、3D marker、`cmd_gimbal` 曲线、串口消息和 `/webots/score`。

### 2. 验证云台方向

保持 `enable_fire:=false`，看目标是否会往画面中心收敛。如果 yaw 或 pitch 越打越偏，翻转对应符号：

```bash
ros2 launch rm_bringup bringup_sim.launch.py \
  launch_webots:=true \
  detector_type:=traditional \
  control_backend:=aimer \
  enable_fire:=false \
  webots_yaw_sign:=-1.0
```

或者：

```bash
ros2 launch rm_bringup bringup_sim.launch.py \
  launch_webots:=true \
  detector_type:=traditional \
  control_backend:=aimer \
  enable_fire:=false \
  webots_pitch_sign:=1.0
```

默认值是 `webots_yaw_sign:=1.0`、`webots_pitch_sign:=-1.0`。只改运动方向符号，不要同时改 `yaw_offset/pitch_offset`，否则不容易判断问题来源。

### 3. 确认分数系统，再开火

方向正确、`cmd_gimbal.mode` 是正常测量后，再开火：

```bash
ros2 launch rm_bringup bringup_sim.launch.py \
  launch_webots:=true \
  detector_type:=traditional \
  control_backend:=aimer \
  enable_fire:=true
```

检查评分：

```bash
ros2 topic echo /webots/score
ros2 topic echo /armor_solver/cmd_gimbal --once
```

`fire_advice` 只有在 yaw 和 pitch 都跟到目标附近后才应该变成 `true`。如果 `fire_advice=true` 但没有命中，优先检查 `webots_yaw_sign/webots_pitch_sign`、仿真相机内外参、`yaw_offset/pitch_offset` 和弹速。

## 不要优先改的东西

- 不要一开始改真实串口协议。
- 不要一开始改相机外参，除非你明确知道当前标定不对。
- 不要打开 `enable_fire`，直到方向、串口协议、下位机解析全部确认。
