# 一、滤波器中最有价值的三个量

如果你的系统有滤波器，通常可以获取以下信息。

## 1 创新（Innovation）

定义：

\[
\nu_k = z_k - H\hat{x}_{k|k-1}
\]

含义：

```
测量 - 预测
```

如果模型正确且目标匀速：

```
创新应该接近0
```

当目标机动：

```
创新持续增大
```

---

## 2 创新协方差

\[
S_k = HPH^T + R
\]

其中：

* \(P\)：状态协方差
* \(R\)：测量噪声

创新大小本身不能直接判断机动，因为噪声可能大。

需要使用 **归一化创新**。

---

## 3 归一化创新平方（NIS）

定义：

\[
\text{NIS} = \nu_k^T S_k^{-1}\nu_k
\]

这是一个非常经典的指标。

如果滤波器一致：

```
NIS ≈ 状态维度
```

如果目标机动：

```
NIS会明显增大
```

因此：

```
NIS > threshold
```

可以作为机动检测。
