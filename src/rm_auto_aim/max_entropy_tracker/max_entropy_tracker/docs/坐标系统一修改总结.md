## 问题描述
原始代码中存在坐标系和yaw角定义不一致的问题：
- 测试代码中：`armor_yaw = armor_yaw_outward + π`（指向内）
- Tracker初始化：`AdaptiveArmorTracker`使用`center = armor + r * unit(armor_yaw)`（错误）
- **双观测更新**：几何计算假设armor_yaw指向内（与新定义矛盾）
- 缺少明确的坐标系文档说明

## 修改目标
统一坐标系定义，明确：
1. 使用**相机坐标系**进行UKF和tracker跟踪
2. `armor_yaw`定义为**中心指向装甲板的径向方向**（外法向）
3. 所有代码实现与此定义保持一致


### 数学验证（第二轮）
```python
# 测试双观测几何计算
center = [1.0, 0.0]
armor1 = [1.2, 0.0], armor1_yaw = 0.0 (径向方向)
armor2 = [1.0, 0.25], armor2_yaw = π/2 (径向方向)

# 反向射线
yaw1_to_center = armor1_yaw + π = π
yaw2_to_center = armor2_yaw + π = -π/2

# 求解射线交点
t1 = 0.2, t2 = 0.25
center_calc = armor1 + t1 * [cos(π), sin(π)] = [1.0, 0.0]
# ✅ 与实际center位置匹配
```
