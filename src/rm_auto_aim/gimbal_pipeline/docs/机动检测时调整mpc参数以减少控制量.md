# 一、精简参数设计

1. **α 计算参数（机动检测）**

* 只使用一个主要参数：

  * `a_max`：期望最大加速度，用于归一化 α

公式：

$$
\alpha = \text{clip}\Big(\frac{|a|}{a_\text{max}}, 0, 1\Big)
$$

* 可选：指数平滑系数 `eta`（0.1~0.3），用于瞬时 spike 平滑

> ✅ 这样 α 的计算只需要 1~2 个参数，简单易调

---

2. **MPC 调整参数**

* 用 α 调整两类权重：

  1. **远期误差项衰减** → 减少远期预测影响

     * 使用一个衰减时间常数 `tau`（步数尺度），公式：

$$
Q_k^\text{eff} = Q \cdot (1 - \alpha \cdot (1 - e^{-k/\tau}))
$$

2. **控制量抑制** → 放大正则项

   * 一个放大系数 `r_scale`：

$$
R^\text{eff} = R \cdot (1 + \alpha \cdot r_\text{scale})
$$

> ✅ MPC 只增加 2 个参数：`tau` + `r_scale`，调参量小

---

# 二、流程简化

1. **计算 α**：

* 输入：当前速度 `v_k` 和上一帧速度 `v_{k-1}`
* 输出：α ∈ [0,1]，短瞬间 spike 会被平滑

2. **调整 MPC 权重**：

```cpp
for (int k = 0; k < horizon; ++k) {
    double decay = 1 - exp(-k / tau);
    Q_eff[k] = Q * (1 - alpha * decay);
    R_eff[k] = R * (1 + alpha * r_scale);
}
u_opt = solve_mpc(Q_eff, R_eff, x0, N);
```

* α=0 → MPC 不调整 → 平稳运动
* α>0 → MPC 保守 → 减少超调

3. **恢复机制**：

* α 由速度差或加速度决定，自然恢复 → 无需额外参数

---

# 三、核心参数总结

| 参数        | 功能              | 调整原则                   |
| --------- | --------------- | ---------------------- |
| `a_max`   | 最大期望加速度，用于归一化 α | 按目标最大机动速度经验值           |
| `eta`（可选） | α 平滑系数          | 0.1~0.3，防止瞬时 spike 过敏感 |
| `tau`     | Q 衰减时间常数        | 预测步数尺度，影响远期衰减速度        |
| `r_scale` | 控制正则放大系数        | 影响 α 高时控制量衰减强度         |

> 总体只有 3~4 个参数，便于快速调试

---

# 四、优点

1. **参数少** → 调参快速
2. **加速度敏感** → 突发机动自动抑制控制量
3. **瞬时 spike 不累积** → 系统鲁棒
4. **自然恢复** → 机动结束后控制量逐渐恢复
5. **易于结合开火策略** → α 高 → 暂停开火
