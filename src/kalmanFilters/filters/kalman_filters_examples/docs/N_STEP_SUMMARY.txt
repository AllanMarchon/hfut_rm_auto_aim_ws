N步预测准确率分析功能 - 快速上手指南
=====================================================================

【新增功能】
评估卡尔曼滤波器在未来1步、5步、10步、20步...等不同时间步长的
位置预测准确率，支持多视野对比和多滤波器性能对比。

【最简单的使用】
python3 scripts/analyze_results.py \
    test_data/cv_3d.csv \
    results/cv_kf_3d_result.csv \
    --n-step

【生成的文件】
1. n_step_predictions.png  - 6张子图的可视化分析
2. n_step_predictions.json - 详细的统计数据

【关键指标】
- RMSE: 均方根误差（对大误差敏感）
- MAE:  平均绝对误差（整体平均水平）
- STD:  标准差（预测稳定性）

【典型结果】
滤波器      1步RMSE   20步RMSE   特点
CV_KF       0.066m    0.143m     有速度，预测较准
CA_KF       0.079m    0.155m     考虑加速度
IMM         0.064m    0.346m     无速度，长期预测差

【常用命令】
# 1. 基础分析
python3 scripts/analyze_results.py data.csv result.csv --n-step

# 2. 自定义预测步数
python3 scripts/analyze_results.py data.csv result.csv \
    --n-step --horizons 1 5 10 20 50

# 3. 对比多个滤波器
python3 scripts/compare_n_step_predictions.py \
    --filters cv_kf_3d ca_kf_3d imm_cv_ca_cs_3d

# 4. 使用便捷脚本
./scripts/test_n_step_prediction.sh cv_kf_3d
./scripts/demo_n_step_prediction.sh

【应用场景】
1-5步:   实时跟踪和控制
10-20步: 短期轨迹预测、碰撞预警
50步+:   长期规划（仅当运动非常规律）

【详细文档】
- N_STEP_README.md      : 完整功能说明
- N_STEP_PREDICTION.md  : 详细技术文档
- N_STEP_QUICK_REF.md   : 快速参考手册

【示例】
cd kalman_filters_examples

# 测试CV滤波器
python3 scripts/analyze_results.py \
    test_data/cv_3d.csv \
    results/cv_kf_3d_result.csv \
    --output analysis/cv_kf_3d \
    --n-step \
    --horizons 1 5 10 20

# 查看结果
ls analysis/cv_kf_3d/
# 输出: trajectory.png, errors.png, statistics.json,
#      n_step_predictions.png, n_step_predictions.json

# 对比多个滤波器
python3 scripts/compare_n_step_predictions.py
# 输出: analysis/n_step_comparison.png (含性能对比图表)
